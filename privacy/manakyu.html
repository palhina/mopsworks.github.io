4. 写真データの取り扱い

本アプリでは、ユーザーが任意でペットの写真をアップロードできます。写真データについて、以下の対応を行っています。

EXIF情報（位置情報等）の自動削除

スマートフォンで撮影された写真には、撮影場所の緯度・経度（GPS情報）をはじめとするEXIFメタデータが含まれている場合があります。本アプリでは、写真がアップロードされた時点で、サーバー側の処理によりEXIF情報を自動的に削除します。これにより、写真から位置情報等の個人情報が漏洩するリスクを防止しています。

写真の保管とアクセス制御
  • アップロードされた写真は、Firebase Cloud Storage に暗号化された状態で保管されます
  • 写真にアクセスできるのは、アップロードしたユーザー本人のみです
  • 他のユーザーや第三者が写真を閲覧・取得することはできません
  • 受け付けるファイル形式は JPEG および PNG のみ、ファイルサイズは5MB以下に制限しています
写真の利用範囲

アップロードされたペット写真は、アプリ内でのペットプロフィール表示にのみ使用します。広告目的での利用、AI学習データとしての利用、第三者への提供は一切行いません。

6. 広告配信とトラッキングについて

本アプリでは、Google AdMob を利用して広告を配信しています。広告配信にあたり、以下の情報が Google により収集される場合があります。

  • 広告識別子（iOS: IDFA、Android: AAID）
  • 端末情報（OS、モデル、画面サイズ等）
  • IPアドレス（おおよその位置情報の推定に使用される場合があります）
  • アプリ内での広告表示・クリックに関する情報
App Tracking Transparency（ATT）について

iOS版をご利用の場合、広告のパーソナライズのためにトラッキングの許可を求めるダイアログが表示されます。これは Apple の App Tracking Transparency（ATT）フレームワークに基づくものです。

  • 「許可」を選択した場合：パーソナライズされた広告が配信されます
  • 「許可しない」を選択した場合：パーソナライズされない一般的な広告が配信されます。アプリの機能に影響はありません

設定はいつでも端末の「設定 > プライバシーとセキュリティ > トラッキング」から変更できます。

広告が表示されるタイミング

ユーザーの学習体験を妨げないよう、クイズの回答中や解説の閲覧中には広告を表示しません。広告は、学習の区切りとなるタイミング（クイズ完了後のボーナスコンテンツ解放時など）に、ユーザーの任意の操作に基づいて表示されます。

7. データの保管・安全管理措置

ユーザーの情報を安全に保護するため、以下の措置を講じています。

  • データの保管には Firebase（Google Cloud Platform）を使用し、通信はすべてSSL/TLS暗号化で保護されています
  • Firestore Security Rules により、各ユーザーのデータには本人のみがアクセスできるよう制御しています
  • Firebase App Check を導入し、正規のアプリからのリクエストのみを受け付けています
  • ペット写真のEXIF情報はアップロード時にサーバー側で自動削除しています
  • クイズやシナリオのマスターデータに対するクライアントからの書き込みは禁止しています

ただし、インターネットを利用したデータ送受信において、100%の安全性を保証することは技術的に困難です。万が一、情報漏洩が発生した場合には、速やかにユーザーへの通知および適切な対応を行います。

データの保管場所（国外移転）

本アプリが利用する Firebase（Google Cloud Platform）のサーバーは、日本国内（東京リージョン）のほか、サービスの種類によっては米国その他の国に所在する場合があります。これにより、ユーザーの個人データが日本国外に移転・保管される場合があります。

Google LLC は、EU-米国間データプライバシーフレームワーク等の適切な保護措置を講じています。詳細は Google のプライバシーポリシーをご参照ください。

データの保持期間

ユーザーの個人情報は、アカウントが有効な間保持されます。アカウント削除時のデータ消去については、第9条をご参照ください。

なお、最終ログインから2年以上経過したアカウントについては、事前通知のうえ、アカウントおよび関連データを削除する場合があります。

Cookie・ローカルストレージについて

本アプリはネイティブアプリであり、Web ブラウザの Cookie は使用しません。ただし、Firebase SDK が認証状態の維持やアナリティクスのために、端末内のローカルストレージを使用する場合があります。

8. ユーザーの権利

ユーザーは、ご自身の個人情報について以下の権利を有しています。

  • 開示請求：当方が保有するユーザーの個人情報の開示を求めることができます
  • 訂正・追加：登録情報に誤りがある場合、アプリ内の設定画面またはお問い合わせ窓口より訂正を求めることができます
  • 利用停止・削除：個人情報の利用停止または削除を求めることができます。アカウント削除の詳細は次項をご参照ください
  • 苦情の申し出：個人情報の取り扱いに関する苦情は、下記のお問い合わせ先にご連絡ください

開示請求等に対しては、ご本人確認を行ったうえで、合理的な期間内に対応いたします。

9. アカウント削除とデータの消去

ユーザーは、アプリ内の設定画面からいつでもアカウントを削除することができます。アカウント削除時には、以下のデータがすべて完全に消去されます。

  • ユーザーアカウント情報（メールアドレス、表示名）
  • ペット情報（名前、種類、年齢）
  • アップロードされたペット写真
  • クイズ回答履歴・学習進捗データ
  • バッジ・ストリーク等のゲーム進捗データ
アカウント削除後のデータ復元はできません。削除操作の前に、確認ダイアログでご案内いたします。

なお、Firebase Analytics により匿名化された集計データ（個人を特定できない統計情報）については、サービス改善の目的で引き続き保持される場合があります。
